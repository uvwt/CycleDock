OAuth 页面成功不等于接入成功。必须确认当前客户端真正发现 CycleDock 工具，并实际调用 list_projects 和 list_cards。

当前工具

list_projectslist_cardsget_cardcreate_discussiongenerate_workupdate_cardmove_cardadd_commentcreate_followupclaim_workheartbeat_runreport_progressadd_findingcheck_infinish_runconfirm_card

重要语义

  • Project 本身就是看板，没有独立 Board。
  • add_comment 只增加长期上下文；只有 create_followup 才创建新 Trigger。
  • Claim 是原子的；一个 Card 同时最多一个 current Run。
  • 外部 MCP 不提供 interrupt。立即转向属于 Human Web 决策。
  • Finding / Result / Check-in 是长期事实；不要上传 raw tool trace 或 chain-of-thought。
  • Agent 只能从 Discussion 生成 Todo / Ongoing；Todo 完成后由 Confirm 进入 Review，最终 Review → Done 由 Human 完成。
  • CycleDock 的 Ongoing Schedule 只创建 scheduled_followup Trigger，不直接运行模型。若还使用客户端自身定时任务，先检查 pending queue，避免重复工作。
